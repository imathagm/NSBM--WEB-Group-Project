# NSBM--WEB-Group-Project
 NSBM web Group -28  ,-----"sports hub management system"
## Events Page - NSBM Sports Hub

The Events Page allows students to explore upcoming sports events
and view past sports activities at NSBM Green University.

### Features

- Responsive navigation bar
- Upcoming sports events
- Search events by name
- Filter events by sports category
- Past events gallery
- Event registration form
- Responsive design for mobile and desktop

### Technologies Used

- HTML5
- CSS3
- JavaScript
